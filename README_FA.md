# پروژه کلاس — Android V2.0

این خروجی بر اساس اصلاحات نهایی پروژه ساخته شده است:
- زبان‌آموزان: دستی و Excel XLSX
- کلاس‌ها: دستی و Excel XLSX
- گزارش روزانه: متن آزاد، ذخیره‌شده همراه کلاس/تاریخ/مدرس
- گزارش هفتگی و ماهانه
- تطبیق روزانه فقط بر اساس نام کوچک؛ نام‌های تکراری نباید خودکار انتخاب شوند
- عدم حدس‌زدن اطلاعاتی که در گزارش روزانه وجود ندارد
- رابط فارسی و RTL

این بسته **سورس Android** است و برای گرفتن APK باید با Gradle/Android Studio یا Cloud Build ساخته شود. APK در این محیط ادعا نمی‌شود مگر واقعاً Build شود.
